# 长兴服务区光伏：典型日约束的气象驱动情景
Windows 接手入口：读取 july_load_pv.csv，按北京时间区间起点与 ../charging_2025/total_hourly_2025_07.csv 对齐。load_kWh 已含充电；pv_kWh 是该小时可用发电量；load_minus_pv_kWh 是储能调度前的净需求，负值表示富余。需要分别计算购电、弃电、储能和外送时直接读取负荷和发电两列。月总发电不能直接视为全部自用。

参考功率来自通讯作者提供的长兴工作表“光伏出力/kW”(未公开)。依据长兴论文第 6.1 节，把原表作为全年 365 天同钟点均值，使用定版 EPW 中的水平总辐射（GHI，上一小时累计 Wh/m²）。对日期 d 和起始钟点 h 计算 PV(d,h) = 参考功率(h) × 1 h × GHI(d,h) / 全年同钟点平均GHI(h)。原表为零的钟点固定为零，此假设省略部分夏季早晚发电。负荷、气象及发电采用同一北京时间区间。逐点吻合由归一化保证；结果是参考原表规模的经验出力情景，未单独模拟组件温度、倾角、逆变器削峰或现场遮挡，缺少独立长兴月电表。不将典型日峰值当作装机容量。若后续优化绝对装机 kWp，应另给有依据的基准装机容量或建立单位装机模型；相对扩容可按基准情景倍率缩放并声明假设。

运行 node simulate.mjs 即可从已有 EPW、参考表、定版负荷表重建 pv_hourly_2025.csv（8760 小时）和 july_load_pv.csv（744 小时）。7 月基准光伏 138570.63 kWh，小时平均峰值 857.30 kW。

external_july_reference.csv 按站、年记录用户提供的河北 PVOD 和国家电网竞赛原始光伏工作表的 7 月样本数和平均功率/额定功率，用于规模归一化后旁证。PVOD 用 power（MW）及 metadata 容量（kW）；竞赛采用 data_original 光伏站工作表 Power (MW) 和文件名装机容量。去空值、重复时间及超出 [0,额定功率] 的记录。15 分钟数据完整 7 月应有 2976 点，样本数不足的行仅描述有效样本。跨地区的实际功率没有拼入长兴时间轴。用 python extract_external.py <两个原始ZIP所在目录> 可重新生成该表。风电留待风电建模阶段。
