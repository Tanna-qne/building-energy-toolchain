# 節能措施掃描

對一批 EnergyPlus 模型套用不同措施,比較用電與總能源(電 + 天然氣)變化。措施與模擬**全部透過 EnergyPlus-MCP 的工具**完成,
這支腳本只負責排程與匯總。

`scan2/scan2.py` 已涵蓋這裡的三個措施,另外有組合、成本與平行執行;這支保留作單純比較用。

## 執行

```
python scan/scan.py
```

輸出 `scan/results.csv`、`scan/report.md`,以及改過的模型 `scan/models/*.idf`。

## 措施

| 名稱 | 工具 | 參數 |
|---|---|---|
| infil_x0.5 | change_infiltration_by_mult | mult=0.5 |
| film_shgc0.30 | add_window_film_outside | U=3.0, SHGC=0.30, VT=0.55 |
| lights_-30% | modify_lights | 依各模型的計算方式,照明功率 ×0.7 |

## 結果(5 模型 × 4 情境 = 20 次,333 秒)

總能源相對基準(括號內是只看用電):

| 模型 | 貼膜 | 照明 −30% | 滲風 ×0.5 |
|---|---|---|---|
| 5ZoneAirCooled | −0.2%(−2.9%) | −10.0%(−16.9%) | −1.5%(+0.0%) |
| 5ZoneAirCooledConvCoef | −0.0%(−2.0%) | −10.4%(−16.6%) | −0.5%(−0.0%) |
| 5ZoneAirCooledDemandLimiting | −3.1%(−1.0%) | −2.8%(−2.2%) | −0.5%(−0.0%) |
| HVACTemplate-5ZoneVAVFanPowered | −2.0%(−5.0%) | −10.5%(−14.5%) | −0.2%(−0.2%) |
| HVACTemplate-5ZoneBaseboardHeat | +0.1%(−0.3%) | −18.9%(−19.8%) | −0.3%(+0.0%) |

## 讀法

- **照明是最有效的單一措施**,但照明減少的發熱要靠暖房補回來,總能源效益約只剩只看電的 6 成。
  DemandLimiting 只有 −2.8%,是因為模型的需量控制白天本來就會壓低照明,再降 30% 能省的不多。
- **貼膜省下的冷房電,大多被暖房多燒的天然氣抵掉**(Chicago 氣候),有兩個模型淨效益接近 0。
- **滲風省的是暖房天然氣**,只看電會以為沒效果。這些範例模型的滲風量本來就小,總能源也只差 0.2–1.5%。

## 限制

- 沒有電價與碳排(成本看 `scan2`)。
- 措施互斥,沒有做組合(組合看 `scan2`)。
- 只用 Chicago 一個氣象檔。
