# 措施組合與回收期

在 5 個模型上分別跑基準、照明 −30%、貼膜、兩者組合、滲風 ×0.5,總共 25 次模擬,並換算年省能源、年省錢與簡單回收期。
每個模型交給一個獨立的 MCP server,最多 4 個同時跑(約 150 秒)。

```
python scan2/scan2.py
```

`db_import.py` 也用這裡的 `scan_parallel()` 跑 DesignBuilder 匯出的模型。

## 成本假設(全部在 `scan2.py` 的 `COSTS`,`sensitivity.py` 也讀這裡)

| 項目 | 假設 |
|---|---|
| 電價 | 4.5 TWD/kWh |
| 天然氣 | 1.5 TWD/kWh(約 16 TWD/m³ ÷ 10.5 kWh/m³) |
| 貼膜 | 1,200 TWD/m² 玻璃 |
| 照明更新 | 600 TWD/m² 樓地板 |
| 滲風 | 沒有成本假設,只看省多少,不算回收期 |

玻璃與樓地板面積取自模擬輸出的 `.eio`,不是手填。樓地板只算有照明的 Zone(不含 plenum)。

## 結果

年省 % 以總能源(電 + 天然氣)計:

| 模型 | 照明 −30% | 貼膜 | 組合 | 組合回收期 | 滲風 ×0.5 |
|---|---|---|---|---|---|
| 5ZoneAirCooled | −10.0% | −0.2% | −11.4% | 9.6 年 | −1.5% |
| 5ZoneAirCooledConvCoef | −10.4% | −0.0% | −10.4% | 10.3 年 | −0.5% |
| 5ZoneAirCooledDemandLimiting | −2.8% | −3.1% | −5.9% | 43.2 年 | −0.5% |
| HVACTemplate-5ZoneVAVFanPowered | −10.5% | −2.0% | −12.2% | 7.8 年 | −0.2% |
| HVACTemplate-5ZoneBaseboardHeat | −18.9% | +0.1% | −18.8% | 11.0 年 | −0.3% |

## 三個結論

1. **照明是主力,回收期約 8–9 年**(DemandLimiting 例外,55.6 年,因為模型白天本來就會壓低照明)。
2. **貼膜在 Chicago 氣候大多不划算**:省下的冷房電被暖房多燒的天然氣抵掉,回收期 7–27 年,Baseboard 甚至 259 年。
3. **電價是關鍵變數**:電價從 4.5 漲到 8 TWD/kWh,組合措施回收期大約砍半(例如 5ZoneAirCooled 9.6 → 5.3 年)。

## 限制

- 成本是假設值,沒有當地報價;回收期對成本與電價非常敏感。
- 只算電費與天然氣費,沒有算碳排、舒適度、維護成本。
- 沒有 discount rate / NPV,只有簡單回收期。
